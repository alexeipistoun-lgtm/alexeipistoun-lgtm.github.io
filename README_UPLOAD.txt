HOW TO UPLOAD
1. Download and extract this ZIP.
2. Open the extracted folder.
3. Select ALL files inside the folder.
4. In the GitHub repository, choose Add file -> Upload files.
5. Drag all selected files into GitHub.
6. Allow GitHub to replace files with the same names.
7. Commit the changes.
8. Keep DSC_0409.jpg and woofwatch image.png in the repository.
9. Wait for GitHub Pages to redeploy.
10. Hard refresh the site with Ctrl + Shift + R.

The site is still a work in progress. Additional project photos can be added later
using the same clickable-gallery layout.
