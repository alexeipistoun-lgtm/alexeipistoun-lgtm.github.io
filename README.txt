STEAKYBONE — VERSION 0 ASSETS

Version:
V0 — Initial Research & Testing

Purpose of this stage:
V0 represents the earliest SteakyBone work before the product became a refined injection-molded
dog chew. This stage should be presented as exploratory research: studying existing chew products,
thinking through size and mass, creating an initial T-bone-inspired CAD concept, exploring mold
manufacturing, and testing how candidate material/process ideas behaved.

Suggested V0 page framing:
Version 0 — Initial Research & Testing

Before committing to a production design, I started by studying existing dog chews, comparing their
size, geometry, and mass, and experimenting with what a SteakyBone-shaped chew could look like in CAD.
The early work also included learning how I might manufacture the product, experimenting with mold
machining, and testing material/process ideas before moving into the first true prototype versions.
